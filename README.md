# MarketPulse — Phase 3: MySQL Integration

[![Phase](https://img.shields.io/badge/Phase-3%20of%204-blue)](https://github.com/experiments-and-learning/market-pulse-real-time-finance-engine)
[![Stack](https://img.shields.io/badge/Stack-Python%20%7C%20MySQL%20%7C%20mysql--connector-informational)](https://github.com/experiments-and-learning/market-pulse-real-time-finance-engine/tree/mysql-integration)

Reads `data.json` and inserts each OHLCV record into a MySQL table. Uses `ON DUPLICATE KEY UPDATE` so the script can be re-run safely without creating duplicate rows.

**Part of:** [MarketPulse: Real-Time Finance Engine](https://github.com/experiments-and-learning/market-pulse-real-time-finance-engine)

---

## What This Phase Does

1. Connects to MySQL using credentials loaded from `.env`
2. Reads `data.json` and extracts the `"Time Series (Daily)"` dictionary
3. Iterates through each date and inserts the OHLCV row into `ibm_daily_stock`
4. Uses `ON DUPLICATE KEY UPDATE` — if a row for that date already exists, it is updated rather than duplicated
5. Commits after each row and closes the connection

## Database Schema

The target database is `real_time_market_pulse_dashboard`. The script writes to the `ibm_daily_stock` table:

    CREATE DATABASE real_time_market_pulse_dashboard;
    USE real_time_market_pulse_dashboard;

    CREATE TABLE ibm_daily_stock (
        trade_date  DATE           NOT NULL PRIMARY KEY,
        open_price  DECIMAL(10,4),
        high_price  DECIMAL(10,4),
        low_price   DECIMAL(10,4),
        close_price DECIMAL(10,4),
        volume      BIGINT
    );

`trade_date` is the primary key, which is what makes `ON DUPLICATE KEY UPDATE` work — re-running the script refreshes existing rows instead of erroring.

## Setup and Run

    # 1. Clone and switch to this branch
    git clone https://github.com/experiments-and-learning/market-pulse-real-time-finance-engine.git
    cd market-pulse-real-time-finance-engine
    git checkout mysql-integration

    # 2. Install dependencies
    pip install -r requirements.txt

    # 3. Create the database and table in MySQL
    #    Run the CREATE statements above in your MySQL client

    # 4. Create a .env file in the project root with:
    #   DB_HOST=localhost
    #   DB_USER=root
    #   DB_PASSWORD=your_mysql_password
    #   DB_NAME=real_time_market_pulse_dashboard

    # 5. Copy data.json from Phase 1 into this directory

    # 6. Run
    python real_time_market_pulse_dashboard_mysql_integration.py

Output: `Data successfully uploaded to MySQL` printed to console.
