# MarketPulse — Phase 2: Data Pipeline

[![Phase](https://img.shields.io/badge/Phase-2%20of%204-blue)](https://github.com/experiments-and-learning/market-pulse-real-time-finance-engine)
[![Stack](https://img.shields.io/badge/Stack-Python%20%7C%20JSON%20Parsing-informational)](https://github.com/experiments-and-learning/market-pulse-real-time-finance-engine/tree/data-pipeline)

Reads `data.json` from Phase 1 and iterates through the nested time-series dictionary to extract and print OHLCV (Open, High, Low, Close, Volume) metrics for each trading day.

**Part of:** [MarketPulse: Real-Time Finance Engine](https://github.com/experiments-and-learning/market-pulse-real-time-finance-engine)

---

## What This Phase Does

1. Loads `data.json` from disk
2. Extracts the `"Time Series (Daily)"` dictionary
3. Converts all date keys into a list
4. Iterates through each date and extracts `open`, `high`, `low`, `close`, and `volume`
5. Prints each day's metrics to console

## Setup and Run

    # 1. Clone and switch to this branch
    git clone https://github.com/experiments-and-learning/market-pulse-real-time-finance-engine.git
    cd market-pulse-real-time-finance-engine
    git checkout data-pipeline

    # 2. Copy data.json from Phase 1 into this directory
    #    Or re-run the Phase 1 script to generate it fresh

    # 3. Run
    python real_time_market_pulse_dashboard_data_pipeline.py

Output: Each trading day's OHLCV metrics printed to console in the format:

    YYYY-MM-DD:
    Open was ...
    High was ...
    Low was ...
    Close was ...
    Volume was ...
